# Customer Support Analytics Dashboard

A beginner-friendly analytics project using fictional support-ticket data. The included Python script summarizes ticket volume, status, response time, resolution time, and satisfaction.

## Run
```bash
python src/support_report.py
```
The script prints a summary in the terminal. Open `data/tickets.csv` in Excel to create PivotTables or charts, or import it into Power BI to build a visual dashboard.

## Suggested Power BI visuals
- Cards: total tickets, open tickets, closed tickets
- Bar chart: ticket count by category
- Column chart: average resolution time by category
- KPI: average satisfaction

## Skills demonstrated
CSV handling, basic reporting, metric interpretation, Excel/Power BI practice.

All data is fictional. This project simulates analytics only; it does not represent actual customer support work.
